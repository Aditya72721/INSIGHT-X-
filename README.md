# INSIGHT-X — AI-Powered Insider Threat Intelligence

INSIGHT-X is a Python-based security monitoring dashboard designed to help organizations identify potential insider threats through employee activity analysis and risk assessment.

## Features

- Employee risk assessment and monitoring dashboard
- Risk scoring and visualization
- Interactive analytics and charts
- Email alert integration
- Telegram alert integration
- Session management and login interface

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Requests

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Aditya72721/INSIGHT-X-.git
cd INSIGHT-X-
```

### 2. Install dependencies

Install the required Python packages used by the project.

### 3. Run the application

```bash
streamlit run main.py
```

## Security Notice

Do not commit passwords, API keys, email credentials, Telegram bot tokens, or other secrets to this public repository. Use environment variables or Streamlit secrets for sensitive configuration.
